Drawer Jam Sort — HTML MVP

Score: 0
Streak: 0
Speed: 1.0x
How to play: Drag items into the matching colored drawer. Make sets of 5 to clear a drawer and score. If any drawer reaches 7 items, it’s game over.
Every few seconds, one drawer may lock briefly (a “jam”). Keep sorting using the other drawers.
Tip: On mobile, use one finger. This is a minimal prototype focusing on the core loop + a simple jam constraint.
