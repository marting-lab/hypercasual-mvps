Design notes (for the Unity build)
- This MVP tests the clarity of the loop: drag → bin → triple-pack → reveal next.
- Add juice later: stamps, confetti, bin lid animation, haptics, sound.
- Level design knobs: queue size, number of bins, unroll budget, hidden ratio.
Target feel
Calm, tidy, fast retries. A “perfect receipt” = finish with unrolls remaining.
