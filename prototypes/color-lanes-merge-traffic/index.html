Color Lanes: Merge Traffic

Minimal HTML MVP — drag cars into lanes. Make 3-in-a-row of the same color in a lane to merge-clear. Don’t overflow.

How to play
1) Drag the newest car into any lane.
2) If a lane ends up with three consecutive cars of the same color, they merge and disappear.
3) If any lane reaches 7 cars, it’s game over.
Tip: try to build triples near the bottom.
Drag the next car into a lane.
Design notes
- This MVP focuses on instant readability for playable ads: drag → lane → triple clear.
- Easy knobs: lane count, overflow cap, spawn distribution, add blockers/locks later.
