# Screw & Slide Blueprint — HTML MVP

Winner idea reference:
- `unity-ideas/22-02-2026/idea-02-screw-and-slide-blueprint.md`

## One-line hook
Unscrew color-coded bolts to clear targets, but the blueprint plates slide after each match, changing what becomes reachable.

## What this MVP tests

- Reachability / blocking readability (covered bolts are dim; reachable bolts glow)
- Two target boxes that clear on 3-of-a-kind
- Deterministic plate sliding after each match

## Controls

- Tap reachable bolts.
- Fill target boxes to 3 to trigger a slide.

## Notes

- This is a simplified logic MVP (not full screw-genre rules).
- Next iteration: dock/limited staging, multiple sliding patterns, level goals, and power-ups.
