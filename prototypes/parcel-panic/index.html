How to play: Tap a parcel card to select it. Tap Rotate if needed. Then tap a valid spot on the van grid to place it. Fill full rows or columns to clear them. If none of the 3 parcels fit, the run ends.
Design intent: easy to read, one-thumb friendly, flat-color art, instant retry.
