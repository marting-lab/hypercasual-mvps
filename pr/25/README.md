# hypercasual-mvps

A repo for ultra-light **HTML MVP prototypes** of hypercasual ideas.

## Goals

- Each idea gets a tiny, playable web MVP (mobile-friendly).
- Each MVP is proposed via a **Pull Request**.
- GitHub Actions deploys PR previews to GitHub Pages under:
  - `/pr/<PR_NUMBER>/`

Example:
- `https://<org>.github.io/hypercasual-mvps/pr/2/`

## Structure

- `prototypes/<slug>/index.html`

## Notes

- Content is kept intentionally simple (no build step).
