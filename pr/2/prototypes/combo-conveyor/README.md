# Combo Conveyor — HTML MVP

Winner idea reference: `unity-ideas/21-02-2026/idea-03-combo-conveyor.md`

## One-line hook
A conveyor brings items nonstop—tap to pull them into 3 trays and clear triples before the belt jams.

## What this MVP tests

- Nonstop belt pressure (items move and can jam)
- 3-tray decision making (choose where to place items)
- Auto-clear on 3-of-a-kind inside a tray
- Streak → speed-up feedback loop

## Controls

- Tap an item on the belt to move it to the selected tray.
- Use Tray 1/2/3 buttons to switch the active tray.

## Notes

- MVP uses a single lane for simplicity.
- Next iteration: multiple lanes, forks, slow-down power-up, item previews, and level targets.
