Drag from a numbered tile to create a rectangle with the same area.
How to play
  • Touch or click a numbered tile, then drag to stretch a rectangle.
  • The rectangle's area must match the clue number inside it.
  • Rectangles cannot overlap, and every tile must be filled.
  • Clear the board to move on. Beat the timer for a better score.
