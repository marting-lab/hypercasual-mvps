Orbit Sort Rush
Rotate the ring. Catch matching colors. Don’t miss.
Score: 0
Hearts: 3

How to play:
  • Swipe left/right on the board (or press A/D) to rotate the 3-bin ring.
  • Catch the falling dot in the bin with the same color.
  • Wrong catch or miss costs 1 heart. At 0 hearts, game over.
  • Complete small goals to trigger FEVER (double points for a few seconds).
